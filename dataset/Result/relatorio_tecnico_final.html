(ii) Pré-processamento dos dados

O pré-processamento é realizado DENTRO do pipeline de Machine Learning, APÓS a separação entre treino e teste, o que garante que as informações do conjunto de teste não "vazem" para o treino.

  • **Tratamento de Ausentes:** Imputação por Mediana para numéricas e por valor mais frequente para categóricas.
  • **Codificação Categórica:** Uso de One-Hot Encoding (OHE) para a coluna 'category'. Colunas de texto/ID foram descartadas.
  • **Normalização:** StandardScaler aplicado apenas aos dados numéricos imputados.
